little thing im working on

something called ComputeCoin (im aware how bad the name is)

ComputeCoin allows people to put spare compute power to use by allowing people rent it out with a coin currency called COMP (temporary name)

I will make this process of renting completley decentralized. Any Tom, Dick, or Harry can rent someones spare compute from smartfridge, laptop, phone, essentially transforming it into a server

Companies can rent out 40,000 nodes on the ComputeCoin network and they would be working together in global p2p, which would replace server hosting. I don't like how aws controls 30% of global cloud infrastructure. This is the fix.

I am almost done with the compute sharing p2p side of it but this is just a POC using python which is unbelievably slow which makes it perfect for a POC.
